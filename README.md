Built my first Data Science mini project — House Price Predictor.

As I've been learning Data Science and Machine Learning, I've been building projects to apply what I'm learning. Starting today, I'll be sharing some of those projects.
The first one is a House Price Predictor — a machine learning web application that estimates property prices across 55 Jaipur localities based on factors such as locality, property type, BHK, bathrooms, area, property age, floor number, furnishing status, and parking availability.

Model: Linear Regression (R² = 0.87)

Dataset: Self-collected and compiled from multiple housing-related sources for learning and experimentation.

Tech Stack: Python, Pandas, NumPy, scikit-learn, Flask, HTML, CSS, JavaScript, Render

Key Learning: Data preprocessing, feature engineering, and domain-specific data collection often have a greater impact on model performance than model complexity.
